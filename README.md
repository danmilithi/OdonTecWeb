# OdonTecWeb

Projeto Integrador desenvolvido em Java.

## Objetivo
Refatorar o sistema desktop OdonTec aplicando princípios SOLID e reorganizando a estrutura do projeto para futura adaptação web.

## Tecnologias
- Java
- Java Swing
- MySQL
- JDBC
- NetBeans

## Estrutura do Projeto
- model
- dao
- service
- util
- view
- main

## Padrões Utilizados
- DAO (Data Access Object)

## Princípios SOLID Aplicados
- Single Responsibility Principle
- Open/Closed Principle
- Interface Segregation Principle
- Dependency Inversion Principle
